## Run a Program

### Requirements

- A C compiler such as GCC
- A terminal or code editor

### Compile

Replace `filename.c` with the name of the source file you want to run.

```bash
gcc filename.c -o program
```

### Execute

**Windows PowerShell**

```powershell
.\program.exe
```

**Linux / macOS**

```bash
./program
```
